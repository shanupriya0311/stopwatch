⏱️ Stopwatch Web Application

A simple and interactive Stopwatch built using HTML, CSS, and JavaScript.
This project helps understand basic JavaScript concepts like DOM manipulation, event handling, and timing functions.

🚀 Features

▶️ Start the stopwatch

⏸️ Pause the stopwatch

🔄 Reset the stopwatch

⏱️ Displays time in hours : minutes : seconds : milliseconds

Clean and responsive UI
